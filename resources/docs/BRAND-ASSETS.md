# Platform brand assets
These local assets were obtained from the platforms' official websites and brand pages. They identify supported platforms; they do not represent partnership or certification.

| Platform | Official reference |
| --- | --- |
| WordPress | https://wordpress.org/about/logos/ |
| WooCommerce | https://woocommerce.com/brand-and-logo-guidelines/ |
| Shopify | https://www.shopify.com/brand-assets |
| Webflow | https://brand.webflow.com/brand-assets |
| Wix | https://www.wix.com/about/design-assets |
| Squarespace | https://www.squarespace.com/logo-guidelines |

Assets live in public/assets/platforms. Original artwork and proportions are preserved. WordPress uses its official W mark. The other platforms use their official wordmarks. Custom web and mobile applications use generic application icons because they are service categories, not brands.
